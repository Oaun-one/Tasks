# Festival collateral and signage permit audit

7 collateral items reviewed against the Heritage Landing standard. 4
carry a finding and 3 are compliant.

| Item | Finding |
|---|---|
| COL-01 | none |
| COL-02 | PERMIT_NUMBER_MISSING |
| COL-03 | EGRESS_MARKER_OBSTRUCTED |
| COL-04 | OVERSIZE_COLLATERAL |
| COL-05 | none |
| COL-06 | none |
| COL-07 | PERMIT_NUMBER_MISSING|EGRESS_MARKER_OBSTRUCTED |

## COL-05 is not a permit finding

COL-05 has no permit number, which looks like the same defect as COL-02. But COL-05 is a
standalone graphic — produced for downstream personal use, never physically installed at
the venue — and the standard's permit, egress and size rules apply only to installed
signage. COL-05 is compliant. Flagging it would be the false positive this audit is built to
catch.

## Other findings

COL-02 is installed signage with no permit number: a genuine finding. COL-03 is installed
signage obstructing an egress marker. COL-04 measures 6 sq ft, above the
3.0 sq ft cap. COL-07 is installed signage with both no permit number and
an obstructed egress marker.
